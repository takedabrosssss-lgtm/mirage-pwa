КАК ПРИМЕНИТЬ
1. Скачайте ZIP и распакуйте его.
2. Откройте GitHub → takedabrosssss-lgtm/mirage-pwa → ветка main.
3. Нажмите Add file → Upload files.
4. Загрузите содержимое распакованного архива в корень репозитория,
   сохраняя папки static, tests и .github/workflows.
5. Подтвердите замену файлов с такими же именами и сделайте Commit changes.
6. После коммита проверьте GitHub Actions → MIRAGE tests.
7. Если Auto-Deploy включён в Render, дождитесь статуса Live. Если нет —
   запустите Manual Deploy для последнего коммита.
8. Откройте приложение и обновите его. При необходимости закройте PWA
   и откройте заново: Service Worker v16 обновит кэш.

ОГРАНИЧЕНИЕ ПРОВЕРКИ
Полный исходный репозиторий не был развёрнут локально для запуска всех
старых тестов проекта. Поэтому полный pytest suite не объявляется
пройденным. После загрузки GitHub Actions запустит весь набор тестов
уже внутри полной копии репозитория. До проверки этого workflow не
включайте автоматическую торговлю на реальном счёте: реальных ордеров
в этой версии всё равно нет.

ОСОБОЕ ПРИМЕЧАНИЕ ПО WIN RATE
Новый фильтр сильнее отбирает сетапы, но никакой код не может заранее
гарантировать максимальный Win Rate. Его нужно подтвердить на достаточной
исторической выборке и затем на отдельном forward paper-тесте. До этого
баллы 86/100 и 88/100 нельзя трактовать как вероятность прибыльной сделки.
